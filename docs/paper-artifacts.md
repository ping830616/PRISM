## Use the exports in Overleaf

Run Section 17E after the Section 17D setup. Upload the generated `.tex` files
from `paper/results/manuscript/` into a `tables/` folder in Overleaf. The
exports use `booktabs` and `graphicx` and retain the paper's labels. Replace the corresponding
existing table environment with, for example:

```latex
% Preamble, if not already loaded:
\usepackage{booktabs}
\usepackage{graphicx}

% At the existing Table IV location:
\input{tables/table-iv-revision-history.tex}
```

Upload the appropriate generated figure to `figs/`. Use `\columnwidth` for a
single column and `\textwidth` inside `figure*` for two columns. Preserve the
paper's figure label and caption rather than using the notebook filename as
its displayed number.
